# Pull-to-Refresh функциональность

## 📱 Обзор

Добавлена современная функциональность **Pull-to-Refresh** для мобильных устройств, которая позволяет пользователям обновлять содержимое страницы простым свайпом вниз.

## ✨ Возможности

### 🎯 Основные функции
- **Touch-based обновление**: Свайп вниз в верхней части страницы
- **Визуальная обратная связь**: Анимированные индикаторы состояния
- **Пороговая активация**: Обновление срабатывает при достижении определенного расстояния
- **Плавные переходы**: CSS анимации для улучшения UX

### 🎨 Дизайн
- **Glassmorphism эффекты**: Современный полупрозрачный дизайн
- **Градиентные цвета**: Соответствие основной цветовой схеме
- **Адаптивный дизайн**: Оптимизация для разных размеров экрана
- **Анимации**: Вращение иконок и плавные переходы

## 🔧 Техническая реализация

### Компонент PullToRefresh
```jsx
import PullToRefresh from '../components/PullToRefresh';

const MyPage = () => {
    const handleRefresh = async () => {
        // Логика обновления
        return new Promise((resolve) => {
            setTimeout(() => {
                window.location.reload();
                resolve();
            }, 1500);
        });
    };

    return (
        <PullToRefresh onRefresh={handleRefresh}>
            {/* Содержимое страницы */}
        </PullToRefresh>
    );
};
```

### Настройки
- **threshold**: 80px (по умолчанию) - минимальное расстояние для активации
- **Сопротивление**: 0.5x от реального расстояния свайпа
- **Время анимации**: 300ms для переходов

## 🎯 Использование

### Для пользователей
1. Откройте любую поддерживаемую страницу на мобильном устройстве
2. Находясь в верхней части страницы, проведите пальцем вниз
3. Потяните до появления индикатора "Отпустите для обновления"
4. Отпустите палец для активации обновления
5. Дождитесь завершения процесса обновления

### Для разработчиков
1. Импортируйте компонент `PullToRefresh`
2. Оберните содержимое страницы в компонент
3. Передайте функцию `onRefresh` с логикой обновления
4. Убедитесь, что функция возвращает Promise

## 🚀 Производительность

- **Минимальное влияние**: Touch события обрабатываются только на мобильных устройствах
- **Оптимизированные анимации**: Использование CSS transforms для плавности
- **Ленивая активация**: События отслеживаются только при scroll position = 0
